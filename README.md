Velox 🦊⚡
Минималистичный, быстрый и абсолютно приватный браузер.
Velox (с лат. «быстрый, стремительный») — это браузер, вдохновленный философией Arch Linux и духом открытого ПО. Он жертвует визуальным шумом ради молниеносной скорости и тотальной конфиденциальности. 
Если классические браузеры — это тяжелые комбайны, собирающие о вас всё, то Velox — это острый скальпель. Он не хранит вашу историю, не строит ваш профиль и не замедляет систему. Как только вкладка закрывается, «хвост» этой лисы стирает всё за собой, возвращая систему в состояние абсолютного нуля.
✨ Особенности

    🕵️ Эфемерный режим (Ephemeral by default): Ни кэша, ни куки, ни истории посещений. Все данные хранятся исключительно в оперативной памяти и бесследно исчезают при закрытии браузера.
    ⚡ Скорость и легкость: Написан на Rust и использует современный движок WebKitGTK 6.0. Минимальное потребление ресурсов.
    Тёмная тема из коробки: Нативная поддержка тёмного режима GTK4.
    ️ Управление с клавиатуры: Продуманные горячие клавиши для быстрой навигации без отрыва от рук.
    🚫 Никакой телеметрии: Браузер не отправляет абсолютно никаких данных третьим лицам.

🛠️ Сборка и запуск
Зависимости (для Arch Linux)
Для сборки проекта вам понадобятся компилятор Rust и библиотеки GTK4 / WebKitGTK:
sudo pacman -S base-devel rust gtk4 webkitgtk-6.0

Сборка
Клонируйте репозиторий и соберите проект в режиме релиза (для максимальной производительности):
git clone https://github.com/ТВОЙ_НИК/velox.git
cd velox
cargo build --release

Запуск
./target/release/velox

⌨️ Горячие клавиши
Velox спроектирован так, чтобы вы могли управлять им, не убирая руки с клавиатуры:
Ctrl + L - Фокус на адресную строку (выделить всё)
Enter - Перейти по URL или найти в Google
Ctrl + R / F5 - Перезагрузить страницу
Ctrl + Shift + R - Жёсткая перезагрузка (игнорируя кэш)
Escape - Остановить загрузку страницы
Alt + ← - Вернуться назад
Alt + → - Перейти вперёд

🗺️ Планы на будущее 
Проект находится в активной разработке. Вот что планируется добавить в следующих версиях:

    Блокировщик рекламы и трекеров: Интеграция фильтров на уровне движка WebKit через UserContentManager.
    Поддержка вкладок: Многооконный режим с управлением через Ctrl+T и Ctrl+W.
    Настраиваемая стартовая страница: Возможность задать свой URL или использовать локальную about:blank.
    Управление загрузками: Минималистичный менеджер скачанных файлов.
    Пользовательские CSS/JS: Инъекция собственных стилей и скриптов для каждого сайта.
